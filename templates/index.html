FAQ
Does ReviewBot work with private repositories? ▼
Yes! As long as your GitHub token has access to the private repo, ReviewBot can fetch and review any pull request — public or private.
How accurate is the AI review? ▼
ReviewBot uses state-of-the-art LLMs to analyze code. It catches most common issues including SQL injection, XSS, hardcoded secrets, and performance bottlenecks with high accuracy.
Can it post comments directly on GitHub? ▼
Absolutely! Toggle the "Post Review to GitHub" option and ReviewBot will automatically post the full AI review as a comment on your pull request.
What languages does it support? ▼
ReviewBot supports all major programming languages including Python, JavaScript, TypeScript, Java, Go, Rust, Ruby, PHP, C++, and more.
